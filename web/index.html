Check your PostgreSQL DDL against ImportFlow’s reviewed Alpha target-schema profile.

Analyzed locally in your browser. Your schema is not uploaded for analysis or saved by this app.

No production approval or migration guarantee. Only supplied DDL is checked. Live schema, permissions, RLS, and trigger effects are not verified. ImportFlow review is still required.

Alpha scope: one public target on Supabase-hosted PostgreSQL 17, for insert-only imports.

Reading the result

          

            
Structural conflict observed
Explicit declarations conflict with the dated Alpha profile.

            
More evidence required
A declared feature or missing declaration needs ImportFlow review.

            
No structural conflict observed
No conflict was found among the declarations evaluated. External review is still required.

            
Analysis refused
The input cannot be fully analyzed under the accepted grammar or input limits. This is not a finding of incompatibility.
